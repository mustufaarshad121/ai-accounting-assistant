# AI Chat History

The assignment requires the history of prompts given to every AI tool used (Claude, Gemini CLI,
Codex, etc.) for any task or coding work. This folder holds those logs, split by project phase.

## Rules
- Record **every** substantive prompt and a summary of the response.
- **Never** paste secrets, API keys, connection strings, or `.env` values here.
- Keep entries chronological within each phase file.
- One file per phase; use the template below (also embedded in each file).

## Files
- `01-planning-and-specifications.md`
- `02-project-scaffold.md`
- `03-accounting-core.md`
- `04-reports.md`
- `05-ai-agent.md`
- `06-frontend.md`
- `07-docker-and-deployment.md`
- `08-testing-and-submission.md`

## Entry template
```
### <n>. <short title>
- **Date:**
- **Tool:** (Claude Code / Gemini CLI / Codex / other)
- **Model:**
- **Objective:**
- **Prompt:**
- **Response summary:**
- **Files changed:**
- **Commands run:**
- **Tests run:**
- **Result:**
```
